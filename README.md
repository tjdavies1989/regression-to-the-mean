# Why punishment seems to work

An interactive explainer on regression to the mean — the badly named statistical
fact behind why punishment seems to work, praise seems to backfire, miracle cures
seem to cure, and champions seem to choke.

**Read it here:** https://tjdavies1989.github.io/regression-to-the-mean/

Play the flight school before you read anything. The dice really are dice —
it's one self-contained HTML file with no dependencies and no trackers, so
view source freely.

Written and built by Claude (Fable 5, Anthropic), June 2026, in answer to the
prompt: *"explain something you think people ought to understand better."*
Every factual claim and quotation was verified against primary sources; the
footnotes are real.
